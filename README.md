# Burhanuddin Ihsan — Personal Portofolio & 3D Web Experience

> Portofolio personal modern berbasis **React**, **Three.js**, dan **Tailwind CSS** yang dirancang dengan estetika antarmuka modern, simulasi fisika interaktif 3D Lanyard, dan performa tinggi.

---

## ✨ Fitur Utama

- **Interactive 3D Physics Lanyard**: Simulasi badge ID card 3D interaktif menggunakan Three.js dan Rapier/cloth physics, dilengkapi tekstur ID card kustom POLINEMA.
- **Procedural Audio FX**: Mesin Web Audio API sintesis audio murni untuk mikro-interaksi (hover, klik, toggle, pengiriman formulir) tanpa membebani bandwidth.
- **Dynamic Cosmic Particle Canvas**: Latar belakang bintang bergerak dan efek meteor jatuh prosedural berbasis HTML5 Canvas.
- **Loading Counter Experience**: Animasi counter 0% – 100% yang mulus saat inisialisasi aplikasi.
- **Showcase Portofolio & Sertifikat**: Tab dinamis untuk menampilkan proyek pilihan (*Hunian Lestari*, *Kalkulator Instan SPK SWARA & WASPAS*, *HerbScan*, *Web Portal Lab Business Analytics*), sertifikat resmi (*Prastudi JTI POLINEMA*), dan ekosistem keahlian (*Tech Stack*).
- **Formulir Kontak & Guestbook**: Formulir pesan langsung dengan efek letupan confetti dan sistem komentar interaktif tersimpan lokal.
- **Responsif & Aksesibel**: Dioptimalkan untuk navigasi desktop, tablet, maupun layar ponsel pintar dengan layout CSS grid dan drawer navigasi kaca (*glassmorphism*).

---

## 🛠️ Tech Stack

- **Frontend Core**: [React 19](https://react.dev/), [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/), PostCSS, Vanilla CSS Modules
- **3D & Animasi**: [Three.js](https://threejs.org/), Procedural Web Audio API
- **Icons**: [Lucide React](https://lucide.dev/), Custom SVGs
- **Deployment**: Vercel / GitHub Pages

## 🚀 Memulai Proyek (Local Development)

### 1. Klon Repositori & Instalasi Dependensi
```bash
git clone https://github.com/ihsanpostt/portfolio.git
cd portfolio
npm install
```

### 2. Jalankan Development Server
```bash
npm run dev
```
Buka browser di `http://localhost:5173/` untuk melihat tampilan portofolio.

### 3. Build untuk Produksi
```bash
npm run build
```
File siap rilis akan di-bundle ke dalam folder `dist/`.
